# 慣性・跳躍・可愛い芝居

小さな喜び跳びや、着地後の追従を作るときのTda限定レシピ。あらゆる「可愛いモーション」をこの2本へ置き換えるものではない。感情、相手、主動作、見せたいポーズを決めてから使う。

## 独立した作例を生成する

`scripts/inertia_recipe.py` はmmd-mcpの既存の骨格／FK／VMD機能を使い、配布モーションを入力せず新規作成する。別モデルへ数値を転用しないよう、Tda式初音ミクV4X Ver1.00のSHA-256を照合する。

```text
python <このスキル>/scripts/inertia_recipe.py --model <Tdaモデルの絶対パス.pmx> --output <新しい出力ディレクトリ> --kind joy
```

| kind | 動き | 終端 |
|---|---|---|
| jump | 浅く溜め、腕を振って1回跳び、脚で着地を受けて静まる | 100F、初期姿勢へ戻る |
| joy | 胸元へ手を寄せ、非対称に両手を開いて1回跳び、着地後に保持、手を再び寄せて笑顔で締める | 144F、締めポーズを保持 |

出力は `motion.json`、`motion.vmd`、`manifest.json`、`trajectory-qa.json`。30fps、26F踏み切り・36F頂点・46F接触・51F最大圧縮。高さ2.6と滞空20Fを固定した検証済み作例で、高さや速度を変更した版は再検証する。

VMDには0Fで左右足／つま先IKをONにする記録も入る。編集用JSONはボーンと表情のみを扱うため、JSONを汎用VMD出力へ渡し直すとこのIK設定は含まれない。独立クリップとして新しい検証シーンへ読み込み、既存の長い芝居へ腕だけのパッチとして重ねない。古いキーを残したままのVMDマージでは同じ結果にならない。

`--no-additional-lag` は比較用。追加の胴体・肘・手の2–3F差を外すが、溜めや着地吸収や反動まで除く「慣性ゼロ」ではない。

## 制作上の判断

汎用の慣性・接地・着地・演技の設計は [モーション制作の知見](motion-principles.md) を読む。ここにある数値は生成器の固定条件であり、他の動作へ適用する基準値ではない。

生成後は踏み切り、頂点、接触、最深姿勢、戻り、保持を確認する。脚の到達範囲の数値検査と、靴底・膝・衣装を含む実機確認を分ける。腕や手の遅延を変えた場合は、時間差の効果と通過姿勢の変化を区別する。

## 適用範囲

この生成器は固定した骨格・高さ・滞空時間を扱う独立クリップ用。任意の接触や向き替え、任意モデルの芝居を生成する機能ではない。靴底の厳密な接触ソルバーや質量重心計算は含まない。条件を変えた版はその条件で検証する。
