# Tda V4X：右手の手振りレシピ

対象はTda式初音ミクV4X Ver1.00の固定した立ち姿。右手の「控えめ」「大きめ」、1〜3往復、速め／標準／ゆっくりを生成する。左右反転、歩きながらの挨拶、他モデル、任意の振り幅はこのレシピの対応範囲に含めない。

レシピ値は [../assets/recipes/tda-right-wave.json](../assets/recipes/tda-right-wave.json)、生成・数値検査は [../scripts/wave_recipe.py](../scripts/wave_recipe.py)。モデル本体や第三者のVMDは同梱しない。

## 選ぶとき

- `quiet`：腕・肘の構えを保ち、掌の面内で手先を小さく振る。顔の横で控えめに挨拶する基礎動作。
- `broad`：肩を上げた構えで腕・肘を使い、大きな弧を描く。手首は折り返しに1F追従する。最後に腕を中央へ上げ直すと余分な振りに見えたため、最後の端で腕を保ち、手首を収めて下ろす。

手を上げて端Aへ到着した後の **A→B→Aを1往復** と数える。上げる・収める・保持・下ろすは往復数に含めない。「2回」が片道2回を意味する依頼なら、まずユーザーの意図に合わせて数え方を扱う。

| speed | 上げる | 1往復 | 収める | 保持 | 下ろす | 終了保持 |
|---|---:|---:|---:|---:|---:|---:|
| brisk | 18F | 18F | 5F | 6F | 24F | 8F |
| normal | 24F | 24F | 6F | 8F | 30F | 10F |
| slow | 30F | 36F | 8F | 10F | 36F | 12F |

`broad` は最終折り返しの手首追従に1Fを加える。全体の最終フレームはmanifestを使う。0〜Nの経過時間N/30秒と、両端を含めた動画N+1フレームの長さを混同しない。指定秒数がこの表と合わない場合、対応済みの速度だと偽らず別条件として検証する。

## 生成

mmd-mcpを導入済みのPythonを使う。スクリプトはライブMMDを操作しない。モデルの絶対パスと、新しい出力ディレクトリを渡す。

```text
python /path/to/mmd-pose-motion/scripts/wave_recipe.py build \
  --model /absolute/path/to/Tda-model.pmx \
  --output /absolute/path/to/new-wave-output \
  --style quiet --cycles 2 --speed normal
```

上記は引数の説明用。PowerShellでは実際のPython・スクリプト・モデルパスを引用して1行で実行し、バックスラッシュを継続記号に使わない。

出力は `motion.json`、`motion.vmd`、`manifest.json`、`validation.json`。出力先が既にある場合は拒否し、元の作品を上書きしない。モデルSHA-256が一致しない場合も拒否する。対象名がTdaでも、別バージョンへ強制適用しない。

ポーズは対応モデルの休止骨格と既存のポーズ計算から構成する。掌を正面へ向ける前腕の回転を求め、手首では休止姿勢の掌法線まわりに回す。別モデルに角度を一律流用しない。生成する手指の形は開いた手と軽く緩めた手に限定する。

## MMDへ適用して確認

現在の作業を確認し、許可された新規シーンまたは専用の空のモデルへ0Fで読み込む。**このVMDは固定した全身の初期値を含む独立クリップ**。既存の演技へ重ねるための腕だけのパッチではない。読み込みがマージになることを踏まえ、古いキーを残したまま時間変更版を重ねない。

Tdaの「AL未使用」は1を含む。足・つま先IKはONで確認し、カメラはモデル正面を基準にする。生成時の掌向き検査は固定したモデル正面を向くかの計算で、任意のライブカメラに正対する保証ではない。

モデルとカメラを揃え、上げる途中、全折り返し、振っている途中、収まり、下ろす途中、終了を確認する。正面では回数・掌・左右の手と胴体の干渉、斜めでは腕の通る位置を見る。比較は物理OFFで行い、仕上げ時は物理ONの実時間再生で髪・衣装も別途確認する。

保存したVMDを読み戻して、生成した同名・同フレームのキー、位置、Quaternion、補間、ALモーフを照合する。MMDが補った初期キーは区別する。PMMを保存し、再生範囲をmanifestの最終フレームへ合わせる。

読み戻したVMDを検査する場合:

```text
python /path/to/mmd-pose-motion/scripts/wave_recipe.py validate \
  --model /absolute/path/to/Tda-model.pmx \
  --vmd /absolute/path/to/readback.vmd \
  --manifest /absolute/path/to/manifest.json \
  --report /absolute/path/to/new-readback-report.json
```

## 数値検査が判定するもの

- 最終フレーム、開始キー、終了姿勢の一致、余計な部位の動き。
- 固定対象のセンター・上体・足IK等。書き出しにIKフラグがあれば、足・つま先IKのOFFを検出する。生成VMD自身にIKフラグは含まれないため、フラグがない結果をON確認済みと扱わない。
- VMDの移動別Bezier補間とQuaternion補間を評価し、腕・手首のFKから手の代表点の往復を数える。代表点は休止姿勢の中指2の位置を手首までの変換で動かしたもので、指先の全関節を解いた点ではない。
- 手の代表点の振り幅、掌が正面を向く度合い、1Fごとの回転量・代表点の移動量。

全身の質量中心、床反力、衣装・髪の貫通、任意の付与・IKを含む全骨格の接触判定ではない。`passed=true` は数値検査の合格であり、その新しいMMDシーンの見た目の合格ではない。manifestの `live_verified=false` は生成直後の状態として保持する。

## 問題が出たら

- 回数不足や振り幅不足：イベント表だけで合格にせず、手の代表点の軌跡、入力VMD、読み込み時刻、古いキーの混在を調べる。
- 接地が崩れる：足IKのローカル値だけでなく、親・全ての親・センター・IK ON/OFFと実機の接触を確認する。
- 掌が裏返る：対応モデル、前腕のひねり、手首の回転軸、親の姿勢を確認する。
- 区間境界で止まる／跳ねる：前後の回転量・区間長・Bezierの端点接線を比較する。非線形曲線があるだけで滑らかだと判断しない。
- 変えるのは原因に対応する部位・区間・設定だけ。新しいファイルへ生成して比較し、数値の閾値を緩めて不自然さを隠さない。

このレシピの折り返し・保持端は止まる意図があるので、停止型の共通曲線を使う。通過点を追加する修正では、同じ曲線を機械的に付けない。

## 知見とレシピの区別

手振りの担当部位、収まり方、掌の向き、補間や往復の数え方は [モーション制作の知見](motion-principles.md) を参照する。このファイルの角度・時間・生成条件はモデル限定の実行仕様として扱い、汎用の推奨値へ転用しない。
