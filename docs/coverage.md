# MMD機能カバレッジ表（v0.3.0）

方針: MMDの制作操作を広く扱う。**済**は公開APIあり、**一部**は明記した範囲のみ、**未**は未実装、**対象外**は理由付きで扱わない。
「済」はMMD全内部状態を読めることや、全モデル・全コーデックでの動作保証を意味しない。
対応環境は日本語配布版MMD 9.32 x64の日本語表示／内蔵English Mode。[言語と名前の扱い](../README.md#ui言語とモデル内の名前) と [ネイティブ編集の手順](native-editing.md) を参照。

| パネル | 項目 | 状態 | API・制約 |
|---|---|---|---|
| フレーム操作 | フレーム移動 | 済 | `mmd_set_frame`、各バッチ |

| | XYZ位置・角度 | 済 | ボーンバッチ、`mmd_get_selected_bone_transform` |
| 表情 | 4カテゴリ選択・値・登録 | 済 | ボーンバッチの `morphs` |

| 照明 | RGB・方向・初期化・登録 | 済 | カメラバッチ、`mmd_get_light`, `reset_light` |

## 継続項目

未実装を上記の「未」に残す。特に、カメラのボーン追従設定、音量、不要キーの自動間引き、VSQ読込、MMEログ取得は今後の追加候補。
また、PMMの全内部キー解析、任意のモデル用意味ポーズの自動較正、任意コーデックの詳細設定、GUI上のマウス操作による自由な範囲選択は対応しない。
公開候補は既存の制作経路とネイティブ出力・MME反映を検証した段階であり、MMD全機能の完全な再実装ではない。

モデルファイルの調査は `mmd_get_model_profile` でPMD/PMXの親階層・軸・付与・IKまで対応。ファイル宣言と初期配置からの推定を区別し、実機の現在姿勢・物理・カメラは解析しない。対象指定は `bone_name` または `bone_index`。
